# Dashboard OPS V2.93 — Restaurant Code Mapping

Ajout:
- Mapping automatique des codes Monday/SAL vers les noms propres du logiciel.

Exemple:
- SAL-0129-LA POCATIÈRE (QC) -> La Pocatière
- SAL-0120-BEAUPORT NORD (QC) -> Beauport Nord
- SAL-0014-CHICOUTIMI NORD (QC) -> Chicoutimi Nord

Le mapping s’applique après chaque synchronisation des plaintes.
